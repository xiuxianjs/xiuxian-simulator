# 灵墟洞天最简 MVP：QQ 交互契约

这是额外最简版的 QQ 展示入口，不替代完整设计。只负责真实服务端页面的展示与操作转交，不在机器人中生成奖励、模拟战斗或缓存权威确认。

最新九品阵法师增量验收见 [气泡批次记录](bubble-style/BATCH-20261111-LINGXU-FORMATION-GRADES.md)。

- 主系统入口：`/灵墟洞天`；副职业入口：`/阵法师`。两者都请求现有业务通道的 `lingxu.command`，`arguments={}`，原完整指令随 `messageText` 传递。
- 私聊展示状态、生命点、入场、倾向、地图、墟行囊、扩容、行记、回执与阵法师。群里只给固定私聊提示，不请求个人状态。
- 行囊每页两物品，保护键位于所属物品名称右侧，绑定实际 holding 短码；数量选择由服务端生成。行囊内部提供扩容入口。
- 行记由服务端提供当前或最近一局最新120条，统一 `nav` 分页；行动记录将经历与收获分别引用，不重复输出本轮消耗。
- 底栏为原 `我｜战｜本｜动｜店`。蓝色指令链接仅填入输入框，发送由玩家决定；不使用不受支持的 `qqbot-cmd-enter show`。
- 新确认只接收服务器 `r1_UID_lx_时间_随机数` 引用，完整指令包含前缀最多80个 Unicode 字符。确认失败保留原引用和原业务操作；没有机器人本地权威 Map。

## 页面数据

```ts
type LingxuPage = {
  title: string; // 灵墟洞天 / 阵法师，或 “主题 · 页面”
  privateOnly: true;
  sections: Array<{
    title?: string;
    id?: string;
    lines: string[];
    experience?: string[];
    harvest?: string[];
    actions?: Array<{ label: string; command: string }>;
  }>;
  actions?: Array<{ label: string; command: string }>;
  nav?: { page: number; totalPages: number; total?: number; command: string };
};
```

可选数组应省略或传 `[]`，不传 `null`。对象至多3键，页末至多8键分两行，全页含翻页至多10键，另有5格原底栏。服务器事实文案原样展示；不完整页面拒绝展示，不补造本地默认状态。

## 阵法师九品成长与12小时阵效

职业复用原副职业记录，无品至九品，经验达到条件自动晋级。职业品阶限制制作和升品；已购高品成品按服务器规则激活，不在QQ另加职业品阶限制。三条路线均为无品基础属性，随后一至九品各一项特色效果，三品、六品、九品为大节点；全部效果来自服务器统一配置。

制作固定一件无品成品，消耗少量洞天材料与10灵晶，基础职业经验10；升品只耗四类洞天材料，每步升至g品的基础经验为10×g。一键升品只固定预览时职业上限及材料允许的目标，不因本次经验触发晋级而继续追加；例如无品升至三品的基础经验合计10+20+30=60。实际经验增益与结算由原职业经验提供者处理，回执展示原成功结果。

职业页显示品阶、经验、下阶需求、可升级上限、当前生效阵盘、剩余时长与截止。我的阵盘每页两件，每件提供“升一品”“一键升品”“激活12小时”，达到上限时显示原因，不提供无效升品键。

激活消耗所选真实成品，确认成功后立即生效12小时；同路线刷新为确认时刻后12小时，不累加剩余时长；不同路线覆盖，不返还成品。终止阵效同样先预览确认，剩余时长与已消耗资源不返还。旧 `/阵法师 装备 d1`、`/阵法师 卸下` 只作为激活/终止预览兼容入口，不直接消费或终止。

各个未冻结的洞天行动读取全局当前有效阵效，已冻结行动保持原快照。激活、覆盖、终止、到期不会倒改已经冻结的行动，也不会通过入场延长12小时时限。行囊容量仍按本局入场快照，和阵效时限分开处理。

制作、升品、激活及终止统一使用服务端Redis `r1...lx...` 原预览引用，缓存包含原品阶、职业状态、实例版本、固定逐级材料及原阵效编号/截止。确认只提交原目标与原操作，不重建最新参数；失败后保留原引用供核对与重试。

## 运行范围

新增入口仍经原机器人身份、中间件与真实 HTTP 通道。服务端须配套注册 `lingxu.command`，并将“灵墟洞天”“阵法师”加入天书功能目录及展示准入；否则生产发送过滤器会隐藏未知指令。未配套时只显示固定失败提示，不伪装成可玩版本。

离线框架测试证明处理器、格式节点、HTTP 契约和发送回执；不等同于 QQ 实机投递、远程数据库结算、部署或十万人压力测试。
