# 本命物基础属性与洗涤词条

适用气泡为「本命物信息」和「本命物详情」。

- 基础属性使用服务端 `basePanels`，展示品级与升级带来的常驻数值。
- 洗涤词条使用服务端 `panels`，展示显现进度、主副异标签及已洗值与上限。百分比词条的两个数值均带百分号。
- 标题为本命物名称和品级。升级与洗涤分别放在等级及词条标题旁，按钮使用服务端下发的可用状态。分离、储物袋和其他可用操作放在底部。回灵与回念效果继续独立展示。

| 改前                                   | 改后                               |
| -------------------------------------- | ---------------------------------- |
| 优先展示当前境界战斗加成，另列洗炼记录 | 上半展示基础属性，下半展示词条属性 |

框架回归使用同一个测试实例，分别提供基础属性、战斗合计和洗涤词条，校验群聊及私聊按上述顺序取值。
