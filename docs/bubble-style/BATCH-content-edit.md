# 签名与宗门内容编辑

- 私聊「我的资料」显示个性签名和 50 字上限。群聊的修改回执提示私聊查看。非空签名通过飞信同款 AI 审核后才保存，私聊资料页显示这一规则。
- 改签名按钮预填命令，由玩家输入正文后发送。直接发送无参数命令仍可清空。
- 宗门简介、公告和精华的用法气泡说明字数计算，并提供预填按钮。编辑命令保留正文换行。
- 本地框架测试覆盖资料展示、签名保存与清空、宗门编辑提示与多行提交。测试通过本地 HTTP 夹具验证机器人请求和发送回执。
