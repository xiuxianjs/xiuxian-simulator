# 鱼类挂牌与鱼讯

鱼类挂牌的预览与确认使用服务端原 `z` 引用。普通垂钓的确认继续使用 `y` 引用。两种引用各自在原操作入口核对格式，预览中的玩家绑定由原解析器检查。挂牌完成和重试均展示带原规则版本的服务端回执。

稀有鱼与鱼王的通知标题为「修仙 · 通知」，鱼讯类型是正文首行。正文保留原鱼种、境界、重量、结果与存在的交战回合。通知的「查看战报」「我的通知」只填入命令。旧鱼讯的原战报命令转换为链接，历史记录同样显示有效原战报入口。

- 隔离 Go 实际挂牌和售鱼 HTTP 响应经过 QQ 处理器回归。预览、确认和重试均使用同一条原引用。测试也覆盖 `y` 与 `z` 的错误入口、其他玩家引用和旧挂牌回执缺规则版本。
- 隔离 Go 实际鱼王通知与历史数据经过真实 QQ 中继和历史处理器。节点检查覆盖新旧鱼讯及稀有鱼展示夹具，核对标题、首行、事实、按钮原编号与手动发送属性。
- 市场、垂钓、授权入口和通知历史四套共 88 项通过。通知最终样稿的中继与历史定向复核 2 项通过，其中历史用例与四套结果重叠。类型检查与改动源 lint 均通过。
- 单尾及区间售鱼在隔离环境返回成功原回执。故意拒绝账本写入时，售鱼事务整体回滚并返回 HTTP 500，QQ 复现「结果待核对」。HTTP 409 显示具体业务拒绝。现网售鱼触发原因仍需对应请求日志核对。

离线预览采用实际处理器节点。挂牌改前图复现旧回执缺规则版本，鱼讯改前图使用旧正文样稿。挂牌错误页的「返回渔获」使用 `/储物袋 渔获`，更新入口后重新捕获的市场套 15 项通过。16 条蓝链都设置 `autoEnter:false`，最长 52 个 Unicode 字符、68 个 UTF-8 字节。输出位于 `D:/data/alemone/bubble-style-mockups/fishing-trade-notices-20261105/`。
