# 送货商队活动入口

个人活动页在「锻造委托」下方显示「送货商队」，点击打开万宝楼商运列表。有车时显示货单和招募状态，无车时显示空列表提示。宗门页不展示此入口。

离线框架运行真实机器人处理器，验收个人与宗门页、无车列表和招募货单。[改前改后与商队列表预览](/Users/lemonade/Documents/bubble-style-mockups/wanbaolou-activity/comparison.png) 根据离线发送节点渲染，未经过 QQ 实机投递。

商队列表页脚提供「打劫队列表」和「我的打劫队」。前者查看公开队伍，后者管理本人的队伍，无队时可创建，两页均可返回送货商队。[页脚改前改后预览](/Users/lemonade/Documents/bubble-style-mockups/wanbaolou-crew-footer/comparison.png)

劫货回执展示车号、货单、当前占用者和守货截止。群回执为可继续争夺的商队保留「立即抢」「组队抢」。未抽中与守方阵容变化有独立提示。真人斗法确认展示基础元力成本，并说明单抢何时离队。[劫货回执改前改后预览](/Users/lemonade/Documents/bubble-style-mockups/wanbaolou-raid-receipts/comparison.png)

功法折扣符统一显示为「惜灵符」，升级报价、确认回执和「我的状态」共用这个名字。已发出的「节费」确认按钮仍走原指令。[改名前后气泡预览](/Users/lemonade/Documents/bubble-style-mockups/wanbaolou-xiling/comparison.png)
