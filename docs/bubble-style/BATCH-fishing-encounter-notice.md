# 垂钓奇遇推送

改前，上古龙鲤只在垂钓主页出现奇遇入口。鱼王和稀有鱼的推送小标题以普通文字显示。

改后，奇遇备妥后通过现有通知中继推送给触发者。推送和通知记录均可打开原奇遇。奇遇默认推送，并沿用通用通知导航。三种垂钓推送的小标题都在引用块首行加粗。

```markdown
修仙 · 通知

> **洞府垂钓 · 垂钓奇遇**
> 水域异动，上古龙鲤现身！
> 境界：筑基 · 大圆满
> 挑战截止：11-07 18:00（北京时间）
> 剩余挑战：3次
>
> ‹查看奇遇›

‹通知设置› ‹我的通知›
```

鱼王和稀有鱼分别加粗「洞府垂钓 · 鱼王渔讯」「洞府垂钓 · 稀有鱼渔讯」。原战报和原奇遇链接都只预填指令。
