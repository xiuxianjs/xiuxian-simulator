# 对话选项样式修复（2026-11-03）

## 修改范围

AgentLink 的统一对话渲染器将有效 `[[选项]]` 转成与普通宿主气泡一致的 `‹选项›` Markdown input；显示包裹符不进入按钮 data。data 保留原无斜杠文本，autoEnter 为 false。超出 80 个 Unicode 字符、带命令前缀或超过单条转换预算的标记转成普通文本，不截断载荷，也不把内部方括号标记漏给玩家。

修仙插件兼容清理模型返回的“退出AI”“退出AI模式”“退出AI对话”“退出AI游玩”，统一为“暂离”。旧按钮识别规则保留，原斜杠玩法不变；宿主没有加入修仙业务规则。

## 验证与边界

真实框架处理器断言 MD.button 的 value、data、autoEnter 和发送回执，覆盖长中文与 Unicode 字符；完整对话处理器覆盖模型返回旧身份割裂文案。布局对照图：`/Users/lemonade/Documents/bubble-style-mockups/dialogue-input-style-before-after.png`，仅为布局示意，不是 QQ 实机截图。
