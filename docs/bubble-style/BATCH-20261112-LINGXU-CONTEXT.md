# 灵墟洞天临场选择与机缘公告

逐轮私聊先显示行记。符合条件时，同条消息增加「动静」「轮次」和临场按钮的引用块。「查看行记」仍在页脚。过期或不合法的选项省略，原结算可照常送达。

宝物现世公告按实际目标群独立投递。同一公告可用 QQ 成员提及提醒多位订阅人，附不同品质的预告文案和「查看机缘」入口。当前群的订阅页展示本人的订阅开关。所有蓝色链接只填入指令。消息图来自 QQBot 离线发送节点。

组队邀请使用队长的可见 UID。队伍行囊展示所有成员合计的容量和暗格，任何成员都可查看。全队成功撤离后随机分配共有战利品，成员分别收到私聊结算，临场按钮只随队长的结算显示。
