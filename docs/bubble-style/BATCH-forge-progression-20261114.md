# 锻造晋升与提前制造

- 自制和委托预览在确认前展示制造者职业阶级、提前制造计入匠师当前阶的预览经验和作品计入的考核阶段。
- `/我的锻造` 在考核达标且经验不足时显示晋升经验差额，提供 `/锻造图纸 练习` 入口。
- 练习图纸按当前职业阶段和正基础经验筛选。暂时缺少材料、灵石或工具的图纸仍可查看详情。
- 两项展示依赖服务端新增的 `professionLevel` 和 `baseExp` 字段，提前制造采用本阶已开放配方中最低的正基础经验，再应用天赋和上限。作品仍在配方所属阶计入考核。
