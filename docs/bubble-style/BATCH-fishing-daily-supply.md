# 垂钓每日补给与饵料效果

2026-11-06

「每日补给」在垂钓状态下方单独一行。持续垂钓时，下一行仍为「结束垂钓」。领取后当天整行隐藏。补给页在每种窝料下显示效果和「领取1份」，六种任选其一。蓝链仅预填原选择和领取日期，发送后领取至储物袋。北京时间每日 0 点刷新。

「更换饵料」页在每种鱼饵的可用数量下显示效果。当前主饵标记和切换入口保留。鱼饵与窝料的效果行只显示钓力、周期及鱼种权重等公开效果。
