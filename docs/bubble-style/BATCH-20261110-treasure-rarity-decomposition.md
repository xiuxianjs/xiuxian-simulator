# 宝物按品质一键分解

分解页新增「一键分解本档满品」。无符合条件的库存时显示固定提示。页脚保留全品质一键分解、切换品质与返回宝物。切换品质页提供六档入口，分解列表使用统一分页导航。

确认页展示指定品质、冻结清单、消耗和预计获得的仙蕴。取消返回原品质。回执展示实际消耗及所得，并提供返回原品质和切换品质的入口。

示例库存为稀有品质满品宝物的 2 个重复本体和 3 枚碎片，合计 23 份，每份 10 仙蕴，共 230 仙蕴。未满品材料由原手动入口处理。

改前和改后使用相同的测试库存，分别由真实机器人处理器生成消息节点。对照图在仓库外的 `bubble-style-mockups/treasure-rarity-before-after.png`。图中为离线消息渲染示意。
