## 2026-11-10 目录体验调整（分类首屏试版）

- `/更多` 导向独立的 `/指令大全`。功能子页在页脚返回上级，移除重复登录、当前分类和通用底栏。导航加载异常时可直接进入静态指令目录。
- `/指令大全` 默认展示玩法分类，可点分类、直接输入 `/指令大全 分类名` 或按总页码查阅。命令卡片纵向展示指令、说明和有值的参数。历史 `/更多 指令大全 [页码]` 指向同一目录。
- 常用写法优先与游戏内按钮一致，例如 `/珍宝楼`、`/查看主线`、`/闭关`。不同操作保留各自指令，历史别名继续由原路由处理。
- QQ 气泡模拟对照图位于仓库外 `bubble-style-mockups/command-catalog-navigation-20261110.png`。

- 表格继续从去除旧别名后的指令数据生成。对照图位于仓库外 `bubble-style-mockups/command-catalog-table-restored-20261110.png`。

## 指令搜索

- `/指令搜索 关键词` 对功能类型和作用做子串匹配。多个空格分隔词均需命中，结果仍用四列表格。
- 表格页脚可填入搜索指令。搜索翻页只发送短引用，进程内最多保留 500 份匹配结果，10 分钟到期，按玩家和会话隔离，关键词不会被保存或回传。
- 模拟对照图为 `bubble-style-mockups/command-catalog-search-20261110.png`。
