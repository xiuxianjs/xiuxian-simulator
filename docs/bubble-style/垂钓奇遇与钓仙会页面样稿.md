# 垂钓奇遇与钓仙会：实装页面样稿

日期：2026-11-05。状态：用户已采用本版页面；后台与处理器测试并行推进，尚不表示这些消息已向QQ真实投递。本轮仅交功能分支，不推main。

沿用已确认的`┃`引用、名称加深与手动蓝链。`**名称**`表示实际bold节点；方括号表示只填入命令、等待玩家手动发送。页面显示值由服务端`FishingView`提供，QQ不计算掉落、参战名单、榜位或奖励。下面是独立账号／时钟的排版示例，不是一名玩家的连续记录。

新增页共13类：奇遇发现、挑战面板、挑战预览、挑战战报、奖励回执、事件结束、掉落说明、赛事主页、鱼种榜、积分榜、排名奖励、升塘转区提示、周结算与领奖。Boss单竿概率0.02%、事件24小时、筑基钓技经验200、周榜第四名以后积分及并列顺序仍按存档候选展示，最终实施默认由服务端统一冻结；已确认规则不据此更改。

## 接线与验收范围

- 所有新消息继续使用`FishingView`，服务端决定`title/sections/lines/actions/navRows/nav/footer/emphasisNames/status`；可选`section.quote`明确引用或普通行，缺省保持旧版排法。QQ仅渲染，名单、金额与排名不在本地Map保存。
- Boss挑战是原`fishing.preview kind=boss-challenge`→`r1_y`→`fishing.confirm`，不直接跳过预览；周奖是独立直接幂等RPC，不能放进只读观察工具自动执行。
- 确认按钮不包含队员数组、鱼数组、长战报或自由文本；完整命令不超过80 Unicode字符，始终`autoEnter:false`且不含`show`。
- 页面确认后生成真实处理器与Format离线节点及改前／改后图，交付记录明确区分服务端隔离测试、QQ发送节点、生产部署和真实平台投递。
