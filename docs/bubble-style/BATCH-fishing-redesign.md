# 垂钓主流程与交易

垂钓主页按空闲、进行中、缺饵、满袋和未建塘展示。配置页提供水域、鱼竿和时长选择，服务端依据主备饵库存、竿速和有效窝效估计可钓时长。收竿回执直达原会话的结算，详列收获、脱钩、战败、用饵和解除预留。

`/商店 渔市` 提供采购及独立货币兑换入口。原渔市命令兼容；回收预览提示对升塘用鱼的影响，确认继续绑定原鱼；珍宝楼列表展示重量与整尾价格，参考价与自定义报价分别展示上架费和成交净得。打窝、捕灵网和升塘在操作前展示相应代价。
