# 宝物分解返回与单件详情

分解列表生成的手动分解、本档一键分解和全部一键分解入口会携带原品质和页码。预览用它生成取消入口，Go 服务将其和原预览保存在同一个短引用中。首次确认或重放回执都使用同一个返回位置。旧指令和旧短引用继续采用原有返回规则。

分解页可以打开操作记录，翻页保留来路，返回后回到原品质和页码。品质选择页取消也回原页。详情展示当前宝物、属性和库存，单件升级或升品的属性变化与消耗从服务端同次确认预览取得。

机器人和 Go 服务的改动需要配套发布，先更新 Go 服务。使用原 Redis 短引用和原操作编号，无需数据库迁移。[改前与改后排版示意](/Users/lemonade/Documents/bubble-style-mockups/treasure-decomposition-return-20261115/comparison.png)
