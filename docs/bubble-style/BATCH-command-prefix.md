# 可配置指令前缀（第一批）

配置 `xiuxian-game.commandPrefix: '**'` 后重启。默认 `/` 兼容已注册的`命令`与`/命令`；未知聊天仍交给其他插件，不进入游戏API。配置 `**` 后只接受 `**命令`，裸命令、旧`/命令`和`**/命令`均不触发。源码按钮可提供裸名称或 `/命令`，发送时统一生成完整指令。支持多字符及正则特殊符号。

路由复用框架 routeText 配置，正则入口同步适配。已匹配处理器内保留 `/指令` 契约，Go API 和凭据不变。任务入口的有意改写继续进入本包；未匹配消息恢复原文交给后续插件。

统一发送出口克隆转换 MD.button、引用块中的按钮、键盘及全局导航；覆盖本地及后端提供的结构化按钮。链接和版本化非中文回调键保留；命令参数不改写，超出 80 个 Unicode 字符明确拒绝，不截断。默认配置同样为裸名称按钮补齐 `/`。

本批不批量改写正文，硬编码命令示例仍有 `/`；平台不透明 Markdown 模板内嵌引用也尚未适配。通知流配置检查不属于本次前缀实施范围。
