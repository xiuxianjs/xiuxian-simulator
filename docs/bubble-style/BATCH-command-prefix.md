# 可配置指令前缀（第一批）

配置 `xiuxian-game.commandPrefix: '**'` 后重启。配置前缀替换 `/`：默认只接受 `/命令`；配置 `**` 后只接受 `**命令`。裸命令和 `**/命令` 均不触发。源码按钮可提供裸名称或 `/命令`，发送时统一生成完整指令。支持多字符及正则特殊符号。

路由复用框架 routeText 配置，正则入口同步适配。已匹配处理器内保留 `/指令` 契约，Go API 和凭据不变。任务入口的有意改写继续进入本包；未匹配消息恢复原文交给后续插件。

统一发送出口克隆转换 MD.button、引用块中的按钮、键盘及全局导航；覆盖本地及后端提供的结构化按钮。链接和版本化非中文回调键保留；命令参数不改写，超出 80 个 Unicode 字符明确拒绝，不截断。默认配置同样为裸名称按钮补齐 `/`。

本批不批量改写正文，硬编码命令示例仍有 `/`；平台不透明 Markdown 模板内嵌引用也尚未适配。通知流配置检查不属于本次前缀实施范围。

## 构造出口补齐

扫描当前 src 的 TypeScript 文件，识别 211 处 addButton 调用。90 个文件中的 207 处命令构造均显式调用 commandText；4 处链接按钮不转换。覆盖 addOptions、FormatGui 的 header/nav/footer/keyboard/bar，以及通知、宗门按钮、教学键盘和各页面直接构造的 Markdown input。源码命令名称不再在这些调用中手工添加斜杠；后端返回 command 在构造时转换。

长度校验使用配置后的实际命令；功能可见性先还原为服务端规范命令再比对。批量装备/功法分解订阅同步识别配置前缀，其提示、确认、取消与实际按钮一致；不再消费裸确认文本。AI 对话的 [[自然语言选项]] 是宿主对话协议，不属于游戏路由指令，保留原协议。
