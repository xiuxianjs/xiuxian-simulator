# 灵墟洞天主页与入门

未入场主页顶部为「简介」「入门」「阵法师」「行记」。状态引用块下保留三行操作，依次为「准备入场」，「行动倾向」「地图」「行囊」，以及「提取回执」。「入门」从各项功能说明直达相应页面。

探索中主页顶部为「简介」「阵法师」「行记」。状态引用块下第一行可返程或休息，第二行可设置行动倾向、打开地图和查看行囊。休息恢复后自动探索。「行动倾向」页内可设置自动返程。

地图外阳内阴，外围和内围各占一页，核心独立一页。地图名右侧显示「前往」，下方只显示产出与出口。八个卦向均有出口，坤门是入场口，也可无条件撤离。出口页逐项展示撤离条件。

行记继续采用一条记录一个引用块和加粗时间。详情只在实际掉落时显示失物去向。败给玩家时由胜者取得失物，败给异种时计入该异种的下一次掉落。

各页保留 `我 / 战 / 本 / 动 / 店` 五格底栏。蓝色链接点击后填入指令。
