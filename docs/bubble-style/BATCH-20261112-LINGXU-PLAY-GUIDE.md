# 灵墟洞天 QQ 页面验收

本批统一所有洞天主页状态的五行信息和行内入口。轮次另起一段，行踪暴露时加粗显示。「玩法」提供八步新手说明，简介保留原故事三段。阵法师入门按键逐步推进，完成后发一份神行材料并引导试制。

八门集中在外围，坤门可无条件进出，其余七门在出口页显示条件和进度。行囊增加丢弃，支持默认一件或手动输入数量。普通操作使用地点、路线或可见数字编号，必要确认保留原凭据。

蓝色按键只填入指令，底栏继续使用「我｜战｜本｜动｜店」。对照和 Markdown 样稿由 Go 页面数据经过真实 QQ 处理器生成。

入场确认和命数耗尽页使用主页的五行排版。入场确认把风险、消耗与时效放在同一个引用块，确认与取消放页脚。洞天相关提示统一使用「命数」。
