# 锻造委托活动入口

「我的活动」个人页在「活跃任务」下方显示「锻造委托」，通过现有玩法可见性筛选，直达委托列表。

[改前与改后 QQ 气泡示意](/Users/lemonade/Documents/bubble-style-mockups/forge-activity-navigation-20261115/comparison.png)

委托列表顶部显示「发起委托」，空列表也可使用。选择图纸后，「填写匠师与工费」会在输入框预填图纸，玩家只需补上匠师 UID 和灵石工费。提交后显示委托预览，点「确认委托」才发布。
