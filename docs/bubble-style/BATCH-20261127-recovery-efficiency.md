# 战斗面板固定显示回灵与回念效率

接口省略恢复效率时，改前战斗属性表跳过整行。改后文字表格和图片面板在命中率下方固定显示该行，分别使用接口给出的数值，缺省值为 0%。

| 属性 | 数值 | 属性 | 数值 |
| --- | ---: | --- | ---: |
| 抗暴率 | 0% | 命中率 | 0% |
| 回灵效率 | 0% | 回念效率 | 0% |
| 闪避率 | 0% | | |

服务端直接按有效的套装、功法、本命物配置计算恢复效率。旧版 `enabled` 字段可留在存量配置中，计算时忽略。未配加成时个人与公开战斗面板均返回两项 0%，原有生效条件与加成上限照常计算。历史初始化 SQL 无需重跑，配置诊断以服务端 `battle-recovery-config-check` 为准。
