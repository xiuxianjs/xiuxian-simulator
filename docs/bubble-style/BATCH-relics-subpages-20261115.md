# 上古遗珍子页

- 概率公示按当前规则读取实际神话保底上限，兼容旧版响应的基础上限。展示现有计数，到达补偿上限时提示已达当前保底。
- 探索确认展示原费用与经验摘要、服务端到期时间，确认和取消都在页脚。神话自选和秘宝兑换的确认页同样使用明确标题及页脚操作。
- 探索记录只展示近期记录数据，复用标准分页，每页三笔，覆盖接口返回的最多二十笔。原记录指令仍打开第一页。
- 图鉴保留品质筛选和旧全局页链接，统一通过标准分页和页脚返回。神话自选展示进度、待领份数及候选当前状态。
- 秘宝商人每件商品独立展示价格、限购和兑换。兑换完成只发送回执，玩家可从页脚刷新当前报价或查看礼盒。
- 探索回执把消耗、经验和奖励放在操作编号之前。同一宝物只显示一次详情入口，同次探索按宝物编号合并奖励，本体和碎片分别累计。探索叙事及原有三秒间隔保留。
