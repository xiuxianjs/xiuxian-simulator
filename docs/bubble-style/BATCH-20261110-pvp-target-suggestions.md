# 打劫与比试候选气泡

单次打劫和比试在目标缺失时显示「附近的修士」。每条显示修士和 UID，附对应的操作按钮。候选仍按同境界筛选，最多显示五条，已观察到的本群道友排在前面，条目上不显示群归属。

改前与改后对照图位于仓库外的 `bubble-style-mockups/pvp-nearby-candidates-before-after.png`。

查看信息、结交、邀请入队、拜师、查看灵田和两种连战在目标缺失时直接列候选。附近修士按已观察到的本群成员优先，灵田沿用可访问灵田列表。队伍踢出、转让队长与已给出合法位置的队伍位置设置仅显示当前可操作的队员。候选按钮保留连战指令及所选位置。

扩展入口对照图位于仓库外的 `bubble-style-mockups/expanded-target-candidates-before-after.png`。

复盘补齐站位两步选择、灵田本群排序、结交名额、拜师冷却与邀请资格反馈。查无道侣目标且未选誓约时显示好友候选页。删除好友未确认时可以从当前好友列表重新选人，选中后仍展示确认。

站位对照图位于仓库外的 `bubble-style-mockups/team-position-candidates-before-after.png`。
