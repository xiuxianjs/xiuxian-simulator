- 基础教学使用具体阶段标题，压缩常态说明；保留真实奖励、消耗、失败原因和挑战/宝箱的有效选择。
- 注册开场保留道号、序章和继续/跳过入口，不铺开天赋说明；原天赋、灵根查询能力不变。

- 宗门主页的升级入口先进入管理页查看条件；宗门、灵脉、商店分别显示所需宗门资源、现有数量、缺口或限制。只有明确 ready 的项目显示升级操作。
- guild.home 新增可选 upgrades 展示字段。旧服务端缺字段显示不可用，不猜测成本；执行仍走原事务，展示不构成锁价或新增确认凭据。
- 使用已有 SDK 等级模型，无数据库结构、经济数值或迁移变更。
