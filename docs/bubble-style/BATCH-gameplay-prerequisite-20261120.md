# 玩法操作简化 · 前置缺口交互

2026-11-20

妖塔挑战缺层间 Buff 时只返回「请先选择层间 Buff」，无标题徽章、无事实行、无按钮，玩家被卡死。现按 gameplay-simplify 归一为三态：唯一合法候选自动启用并打完本层；多个平级候选给预选与候选供确认，不静默代选；无合法候选报精确星数差。缺口气泡改用 `errorBubble` 组件（❌ 徽章 + 单一引用块 + 页脚返回），事实行统一「原因／需要／现有／还差／预选／可选／待选」标签，精确到数字，不出「不足」。

单候选启用后回执显示「自动加成：X」，并注明可用 `/妖塔选buff` 更换，因为层间加成只在本轮生效、可免费切回。

对照图与可复制原文位于 `D:/data/alemone-cloud/bubble-style-mockups/gameplay-simplify-20261120/before-after.png` 与同目录 `before-after.html`。

同一批还改了两处前置：炼丹只拥有一件可接入 V2 的天工（或一类都没启用）时同事务自动启用，补领天工在没有任何该类天工启用时顺带启用（可随时 `/炼丹 卸下`，交易与收藏权限仍保持收回）；垂钓在玩家自己指定的鱼竿不可用时给出鱼竿选择页，但鱼竿来自历史记录时不改用别的竿，继续拒绝。
