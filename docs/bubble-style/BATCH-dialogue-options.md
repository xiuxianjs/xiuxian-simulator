# 对话选项保留原指令（2026-11-03）

教学回执 actions、entries、branchMenu 的 command 不再被丢弃。可用原指令在完整 80 Unicode 字符预算内时，保留全部参数，仅去掉开头斜杠；超过预算不截断，回退原说明标签让对话重新核对。模型使用当前回执的唯一标签时转换为对应指令文本；同名分支不猜测对应关系，非当前回执选项不做转换。

分支目录补齐模型漏列的选项；投递记录与宿主 Markdown input 都支持最多 80 Unicode 字符，原确认凭据及授权逻辑不变。宿主只扩展通用渲染长度，不加入修仙词表。真实处理器覆盖十五分支、带版本及参数的长指令、发送成功与下一轮识别；宿主覆盖 24/25/79/80/81 字符及非 BMP 字符。
