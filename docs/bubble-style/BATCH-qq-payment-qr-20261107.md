# QQ 充值二维码

新订单和继续支付气泡移除「打开支付页面」外链按钮，提示使用下方的二维码。查询结果和原订单恢复命令仍可用。代码在两处气泡及共享发送函数中注明 QQ 内打开链接无法完成付款，避免恢复外链入口。

机器人使用同一订单的收银台地址生成支付二维码。支付面板生成失败或发送回执失败时，改用独立 PNG 图片消息补发。二维码仍未确认送达时提示从我的订单恢复，恢复操作沿用原订单。

[改前与改后示意图](/Users/lemonade/Documents/bubble-style-mockups/qq-recharge-qr-before-after.png) 使用示例订单及示例链接。

本地验证通过 TypeScript、ESLint 和 123 项定向框架测试。框架测试覆盖真实机器人处理器、发送节点、回执和原订单恢复。旧普通充值展示夹具的群聊调用断言在修改前后均失败。尚未部署，尚无 QQ 实机付款结果。
