# 灵墟洞天行记与推送设置

行记中每条记录单独使用一个引用块。北京时间作为加粗标题，行记、行动详情、提取回执和每轮私聊推送统一使用 `2026.11.12-20:40` 的格式。引用块下方依次展示经历、结果、收获及实际掉落。有收益或物品掉落时才显示对应的行。每条记录底部的 `‹详情›` 填入原记录指令，详情页查看交手对象、战斗结算、资源实扣及损失。历史服务端返回的分段行记仍可显示。

行记页脚提供 `‹提取回执›`、`‹推送设置›` 和 `‹返回洞天›`。私聊和群聊都可开启逐轮私聊推送或关闭推送。旧推送只有月日时，依据事件内实际结算轮次补全年份。临场按钮仍使用原有轮次指令。

底部沿用 `我 / 战 / 本 / 动 / 店`。列表详情、分页、推送设置和返回按钮均为填入式。

初版的框架范围 TypeScript 检查及含 Go 页面契约的 37 项洞天 QQ 框架测试通过。整体 TypeScript 检查仍报相邻 `alemonjs-agent-link` 缺少已构建模块。
