# 灵墟洞天行记与推送设置

行记中每条记录单独使用一个引用块。时间作为加粗标题，下面依次展示经历、结果、收获及实际掉落。有收益或物品掉落时才显示对应的行。每条记录底部的 `‹详情›` 填入原记录指令，详情页查看交手对象、战斗结算、资源实扣及损失。历史服务端返回的分段行记仍可显示。

行记页脚提供 `‹提取回执›`、`‹推送设置›` 和 `‹返回洞天›`。群内可选择将行记推送到本群，私聊和群聊都可选择推送到私聊或关闭。QQ 指令只接受固定选项，群目标取自收到设置指令的事件。

底部沿用 `我 / 战 / 本 / 动 / 店`。列表详情、分页、推送设置和返回按钮均为填入式。

框架范围 TypeScript 检查通过。含 Go 页面契约的洞天 QQ 框架测试共 37 项通过，覆盖群聊和私聊的消息发送节点、真实群目标传递及频道目标拒用。整体 TypeScript 检查仍报相邻 `alemonjs-agent-link` 缺少已构建模块。
