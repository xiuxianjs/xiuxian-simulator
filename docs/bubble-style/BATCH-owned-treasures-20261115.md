# 我的宝物

首页展示已激活件数、经验、仙蕴和当前境界等级上限。默认按编号分页列出所有已激活宝物，多种品质才显示筛选。每件只列名称、编号、品阶、等级和详情。空库存提供上古遗珍入口。

首页页脚连接属性面板、效果总览、批量培养和分解。鸿蒙气运从效果总览进入，一键升级和突破移到批量培养页，操作记录从批量培养打开并按每页五笔分页。分解保持自己的品质、库存和确认流程。旧的培养、分解和图鉴指令仍可读取，宝物页清除灵脉租契和重复导航。

离线框架检查群聊和私聊发送节点、全部与品质分页、按钮往返和确认凭据。[改前与改后排版示意](/Users/lemonade/Documents/bubble-style-mockups/owned-treasures-20261115/comparison.png)
