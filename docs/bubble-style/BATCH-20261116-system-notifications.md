# 个人系统通知合并

- 已识别的非飞信通知按事件类型和结果分组。组标题只显示一次，已知且一致的规则或状态放在组头，共用列表入口放在组尾。
- 邮件名称、悬赏到账金额、委托编号、作物、关系事件与原物交付信息保留在各自条目。战报、渡劫结算和垂钓奇遇入口与原事件绑定。
- 旧服务端只下发正文时，按事件类型补充已知标题。同批关闭按钮按分类去重，其他分类按钮写明「关闭其他及旧版通知」。
- 通知历史保留时间和正文。合法的打劫事件编号和对应战报生成独立按钮，替换该条重复的原命令。
- 对照图位于仓库外 `bubble-style-mockups/system-notifications-20261116/comparison.png`。覆盖系统邮件、悬赏到账和反击结果。

## 通知设置

- 天书指令目录登记「通知设置」，发送时保留每个可见分类右侧的「开启」或「关闭」链接。点击后填入该分类的指令，由玩家发送。
- 当前列表隐藏「黑盒」分类。其余分类各自保存个人主动推送偏好，通知记录照常可查。
