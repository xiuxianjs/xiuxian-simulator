# QQ 输入回显治理

珍宝楼、商店、词典和物品详情的可见提示移除查询原词。词典拒绝审核时统一提示修改后重试，失败按钮只保留固定入口。发红包、职位、拉黑、分解品级和悟道的拒绝提示使用固定文案或允许值。

- 改前与改后对照图位于仓库外的 `bubble-style-mockups/qq-input-feedback-20261110.png`。
- 飞信首页、月卡权益和扫荡排名从校验过的字段生成刷新或继续操作指令。
- 珍宝楼搜索的排序与分页使用绑定玩家的 Redis 编号，有效期为 30 分钟。服务端无法提供编号时保留当前查询结果，提示重新输入关键词。按钮载荷对照图位于仓库外的 `bubble-style-mockups/market-search-reference-20261110.png`。
- 商店筛选、切店和翻页，以及词典搜索翻页使用 30 分钟的 Redis 搜索编号。词典的公共入口按服务端确认的平台身份隔离。按钮载荷对照图位于仓库外的 `bubble-style-mockups/shop-glossary-search-reference-20261110.png`。
- 词典分类、礼盒、秘境、道具消耗、锁定、道侣和阵盘的部分失败提示移除原始参数。QQ 图鉴只传固定的已知子分类，动态天工类型及未知子分类改由网页选择。失败提示对照图位于仓库外的 `bubble-style-mockups/qq-failure-feedback-20261110.png`。
- 炼丹通信异常时，仅为符合协议格式与字符预算的原凭据生成重试按钮。渡劫和心魔的重试按钮由解析出的指令与编号重建。
- 词典编辑申请保留运营审核所需理由，QQ 仅确认提交成功。申请回执与确认重试对照图位于仓库外的 `bubble-style-mockups/qq-application-retry-20261110.png`。
- 已知旧回执按业务操作清理失败文案，覆盖 HTTP 拒绝和业务回执。储物袋自定义子分类在失败时退回已知上级分类，旧回执的按钮也按同一规则重建。改前改后对照图位于仓库外的 `bubble-style-mockups/legacy-feedback-safety-20261110.png`。
- 词典录入与反馈提交必须成功刷新敏感词库后才进入写入。读取成功的空词库可以正常处理，读取失败不会保存文本或消耗提交额度。故障行为对照图位于仓库外的 `bubble-style-mockups/content-review-outage-20261110.png`。

### 历史内容覆盖核对

- MIS 默认扫描目标包含道号、签名、宗门名、宗门简介与公告、反馈、词典、宗门精华、战斗预设名和自定义主题名。默认目标未包含飞信历史正文。
- 飞信新写入由服务端实时审核。现有历史记录的审核覆盖需要依据各服实际配置、扫描检查点和生效时间另行核对。

### 道号与宗门名称审核

- 注册选性别和建档使用可读取的共享词库，去除进程内永久快照。共享缓存未命中时读取数据库，读取失败时暂停。玩家改名、创建宗门和宗门改名在词库读取失败时停止在扣卡或扣费之前。
- 故障对照图位于仓库外的 `bubble-style-mockups/name-review-outage-20261110.png`。
- 战斗预设和自定义主题的玩家命名经敏感词库校验。审核失败或词库读取失败时停止写入，保留原预设和主题配置。预设仅使用固定系统名称时可以正常保存。对照图位于仓库外的 `bubble-style-mockups/custom-name-review-20261110.png`。
- QQ 新生成的预设列表和应用回执、自定义主题列表和切换回执使用当前敏感词库校验历史名称。命中或词库不可用时使用固定展示名，保持原数据、槽位、编号和实际操作。系统主题沿用配置名。展示对照图位于仓库外的 `bubble-style-mockups/historical-name-display-20261110.png`。
- 名称替换在机器人业务投影生成时执行。新业务回执以 `namesReviewed: true` 标记名称投影。旧服务端和此前已缓存的回执缺少标记时，机器人用槽位名或通用名展示，系统主题列表保留系统名称。对照图位于仓库外的 `bubble-style-mockups/legacy-name-receipt-20261110.png`。

### 旧飞信通知

- 旧飞信主动通知缺少有效的结构化资料时，不使用原始通知载荷作为备用展示。通知历史中的旧飞信条目也使用固定提示「你有飞信记录，请查看飞信。」和「查看飞信」按钮。对照图位于仓库外的 `bubble-style-mockups/legacy-flymail-notice-20261110.png`。
- 待核对的结构化正文来源包括五类飞信列表、好友会话预览和会话详情、好友发信成功附带的会话历史，以及通知推送与通知历史。结构化资料可以验证字段类型和编号，不能作为历史正文已通过审核的证明。
- `fly_messages` 的现有模型保存会话、发件人和正文，没有逐条审核状态。新发信在写入前调用审核，但旧行、历史回执和旧出站通知不能仅凭字段齐全推定为已审核。
- 新发信通过正文审核后，写入同一事务的通知载荷带 `contentReviewed: true`。QQ 私聊推送和通知历史只为带该标记的结构化通知展示正文及回复按钮。旧结构化通知继续使用固定提示，保留校验后的会话入口。对照图位于仓库外的 `bubble-style-mockups/structured-flymail-notice-20261110.png`。
- QQ 飞信列表、好友会话预览和详情，以及发信成功附带的历史正文，使用通知存档中的审核标记。服务端按当前页的消息编号查找通知，并比对会话编号及完整正文。缺少记录、已清理、查询失败或正文不一致时，QQ 显示「正文暂不可展示。」并保留已有会话、回复和分页入口。旧服务端或缓存回执缺少标记时同样处理。对照图位于仓库外的 `bubble-style-mockups/flymail-history-review-20261110.png`。
- QQ 发信业务拒绝只展示已知的完整提示，旧回执中的拼接文案退回固定提示。AI 审核拒绝与词库拒绝均保留不含原正文的重新编辑入口。对照图位于仓库外的 `bubble-style-mockups/flymail-review-feedback-20261110.png`。
- 飞信正文审核记录与显示名称相互独立。好友会话标题由道号与 MID 或 UID 组合，消息和通知还读取发件人道号。QQ 飞信列表、会话标题和发送回执在服务端单独使用当前词库检查显示名称，命中或词库不可用时改用 UID。旧机器人回执无名称校验标记时也按 UID 展示。新通知独立记录发件人名称校验结果，旧通知及无标记名称使用 UID。对照图位于仓库外的 `bubble-style-mockups/flymail-display-names-20261110.png`。
- QQ 飞信屏蔽与解除使用固定成功回执，解除按钮只带校验过的 UID。查看及屏蔽的业务拒绝使用固定提示，刷新、返回和查看入口由机器人重建。对照图位于仓库外的 `bubble-style-mockups/flymail-mute-view-feedback-20261110.png`。

### 词典写入成功回执

- 创建、更新和删除使用固定成功提示。录入回执保留分类、额度、返回词典和继续录入，移除携带原始词条名的查看按钮。对照图位于仓库外的 `bubble-style-mockups/glossary-write-feedback-20261110.png`。
- 秘境结算的继续挑战按钮使用服务端返回的有效秘境编号，点击时调用既有编号挑战分支。手动按名称挑战继续可用。结算回执异常时使用固定提示。对照图位于仓库外的 `bubble-style-mockups/dungeon-retry-id-20261110.png`。
