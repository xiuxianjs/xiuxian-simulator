# 修仙帮助与成长指引

`/帮助` 打开帮助首页，`/修仙帮助` 保留为同一入口。成长指引保留三页，分别介绍首日操作、炼气阶段和九层起的玩法。每页集中呈现当前阶段的行动和常用入口，详细解锁条件可查天书。

指引页与商店共用 `FormatGui` 的 `nav`，展示页码和可用的上一页、下一页。返回帮助入口放在页脚。未注册玩家也可阅读指引，并可从页脚踏入仙途。

本地发送节点的第二页对照图位于仓库外的 `bubble-style-mockups/help-pagination-20261112/comparison.png`。定向框架测试从真实路由进入，覆盖群聊、私聊、按钮往返、页码边界及发送回执。
