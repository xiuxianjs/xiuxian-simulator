# 修为和战斗属性使用中文大数单位

`/我的信息` 使用当前修为和境界上限数值生成气泡。战斗属性表的固定数值在 `/查看信息`、`/属性面板` 和 `/属性面板图` 使用同一套中文数字格式。满万使用中文单位，最多保留两位小数。百分比继续使用 `%`。

| 示例     | 调整前                 | 调整后           |
| -------- | ---------------------- | ---------------- |
| 修为     | 1.199586e+06/2.368e+06 | 119.96万/236.8万 |
| 物理攻击 | 42,599                 | 4.26万           |
| 生命上限 | 341,323                | 34.13万          |
| 灵力上限 | 640                    | 640              |
| 暴击伤害 | 413%                   | 413%             |
