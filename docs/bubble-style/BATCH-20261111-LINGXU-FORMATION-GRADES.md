# 阵法师九品与12小时阵效增量验收

沿用本轮已完成的最简 MVP，新增无品至九品成长。没有读取被用户作废的旧洞天实装，也没有改变原完整设计文档。当前交互契约见 [lingxu-minimal-mvp-qq.md](../lingxu-minimal-mvp-qq.md)。

职业页展示品阶、经验、下一阶需求、升品上限、当前阵效及剩余/截止。路线详情直接展示服务器统一配置的基础效果与九项机制，三品、六品、九品标“大节点”。成品列表每页两件，每件最多“升一品、一键升品、激活12小时”三键，含分页与返回不超过10键，另有原五格底栏。

制作、升品、消耗激活与不可返还终止都先生成预览，再确认原 `r1...lx...` 引用。旧“装备”“卸下”指令现在只读取预览，不直接消费或终止。确认缓存包含原职业状态、实例品阶/版本、固定目标及逐级材料、原阵效编号/截止。经验结算后的职业晋级不会额外追加未确认的升品。

阵效与行囊快照分开：各未冻结行动读取当前全局有效阵效，已经冻结的行动保持原快照；激活立即消耗成品，12小时从确认成功时开始计时，同路线刷新不累加、异路线覆盖不返还。行囊容量仍从下一局使用新容量。
