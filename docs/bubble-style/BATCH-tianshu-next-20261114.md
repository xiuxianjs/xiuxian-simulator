# 天书内容精简

原默认页同时展开两个大境界。以炼气四层为例，规则表中炼气和筑基合计 43 项，每项原先单列说明和附加条件。新默认页按实际下一小境界展示新增玩法，此例只列炼气五层的道侣、通天塔和声望商店。下一境界无新增时显示空态。

`/天书 炼气`（兼容「练气」）等大境界页每页最多六项，显示开放门槛与附加条件。`/天书 目录` 可点选境界，保留原数字入口和通用页。

规则对照示意图位于仓库外 `bubble-style-mockups/tianshu-next-20261114/comparison.png`。

炼气目录按小境界合并，每页最多两组，保留影响参与的条件。用服务端目录和真实机器人路由复测，四页正文分别为 147、39、111、76 字符，共 8、5、8、4 行。计数排除空白、页眉、按钮和客户端自动折行。群聊与私聊均验证了翻到末页及返回上一页。改前改后对照位于仓库外的 `bubble-style-mockups/tianshu-grouped-20261114/comparison.png`。

下一境界预告、境界目录和炼气分层条目可直接打开对应的境界帮助。境界帮助给出玩法步骤与资源建议，个人进度由帮助首页查看。境界目录每页三项，为每项的查看和帮助按钮留出空间。
