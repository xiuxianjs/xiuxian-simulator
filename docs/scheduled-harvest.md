# 预约采收提供方（2026-11-03）

修仙插件新增独立 `agent.scheduled-action.v1` 协议。`prepare` 是授权签发操作，只在真实消息与明确预约请求下使用当前绑定角色。签名绑定调用插件、平台、机器人、用户、群或私聊、地块、起始时间、重复间隔、失效时间和后端地址。签名使用配置中的后端凭据作为密钥并使用专用域前缀；凭据轮换会使旧授权失效。签发不等于宿主已保存预约，不执行采收。

`execute` 拒绝实时聊天上下文，只接受独立后台调用；复核调用插件、配置、有效期、原轮次与实时角色绑定。只调用已有的 `/api/v1/players/{id}/cave/plots/harvest`，服务端事务负责最新成熟条件与收益。幂等键由完整签名授权和原轮次推导，宿主改变重试编号不能产生另一结算键。已知未成熟冲突返回 skipped，无法确认的传输或回执结果返回 unknown。

没有增加游戏数据库字段或 SDK 模型，不改核心数值。使用真实 Expose 处理器和 HTTP 客户端，HTTP 服务响应使用隔离夹具；不代表在线账户结算或 QQ 实测。新框架测试命令：

```sh
AGENT_PLAY_FRAMEWORK_ROOT=../alemonjs/packages/alemonjs node tools/run-agent-play-tests.mjs --filter=scheduled-harvest
```
